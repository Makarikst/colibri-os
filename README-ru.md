**Colibri OS** — маленькая hobby-операционная система для архитектуры **i386**, написанная на C и ассемблере. Загружается через **multiboot**, работает в **защищённом 32-битном режиме**, имеет собственную оболочку, файловую систему и набор встроенных команд.

## Возможности

- **VGA-текстовый режим** 80×25 с цветами (16 палитр)
- **Интерактивная оболочка** с приглашением `colibri:/users/alpha>`
- **Собственная файловая система** (файлы и каталоги в памяти)
- **Встроенный калькулятор** с операциями `+ - * / % ^`
- **Математика**: `sqrt`, `pow`, `gcd`, `lcm`, `prime`, `rand`, `hex`, `bin`
- **Переменные окружения** и **алиасы команд**
- **Заглушки** для процессов и сети
- **Загрузка через multiboot** — работает с QEMU, GRUB, VirtualBox

## Быстрый старт

### Требования

- `x86_64-elf-gcc` — кросс-компилятор
- `x86_64-elf-ld` — линковщик
- `qemu-system-i386` — эмулятор

### Сборка и запуск

```bash
git clone https://github.com/Makarikst/colibri-os.git
cd colibri-os
./build.sh
```

После сборки создаётся файл **`colibri.cos`** — ELF-образ ядра. QEMU запустит его автоматически.

Ручной запуск:

```bash
qemu-system-i386 -kernel colibri.cos -m 16M -net none -vga std
```

## Как это работает

### Загрузка

Ядро оформлено как **multiboot-совместимый ELF**. QEMU или GRUB читает multiboot-заголовок в первых 8 КБ и передаёт управление на `_start`.

```asm
.section .multiboot, "a"
    .long 0x1BADB002    # magic
    .long 0x00000003    # flags
    .long -(MAGIC + FLAGS)
```

### Память

- Ядро: `0x100000` (1 МБ)
- Стек: `0x9F000`
- Куча: `0x200000` (2 МБ)

### Файловая система

In-memory ФС: массив объектов `FsObject` с типом (`FILE` / `DIR`), именем, родителем, данными (до 4 КБ на файл).

## Запуск на реальном железе

Собери `colibri.cos` и положи на флешку с GRUB. Пример `grub.cfg`:

```
menuentry "Colibri OS" {
    multiboot /boot/colibri.cos
    boot
}
```

Установка GRUB на флешку:

```bash
sudo grub-install --target=i386-pc --boot-directory=/mnt/usb/boot /dev/sdX
```
